# Website-copy handoff structure

For each requested page:
- Page purpose, primary visitor and intended action in a short designer note.
- Finished H1, headings, body and CTA labels in the page's actual reading order.
- Relevant microcopy and honest proof from supplied sources.
- SEO title, description, proposed slug and keyword rationale when applicable.
- Separate language editions if requested.
- Link destinations and genuinely unresolved content facts in an editorial note.

Do not add a section merely to fill this template. Do not deliver only headings when full copy was requested.
