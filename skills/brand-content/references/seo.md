# SEO for articles and website copy

Use the latest user-supplied inventory, not a workbook path or keyword list remembered from another task. Inspect sheet names, headers, brand, language, intent, source date and missing fields.

Select a coherent cluster:
- one primary intent;
- a small set of supporting phrases;
- genuinely useful related terms;
- separately labelled new candidates requiring validation.

Workbook volume/KD are historical values unless freshly checked. Preserve blanks as unknown, not zero. Never invent metrics or promise rankings. Brand match is required; “AZMX client” does not make a Colab term interchangeable.

For each chosen term explain why it fits and where it belongs: headline/introduction, relevant section, metadata or contextual link. Use natural phrasing, not a density target. An Arabic phrase such as تصميم تجربة المستخدم can coexist with English technical names.

For English, validate intent independently rather than assuming literal translations have the same demand. Do not claim an English seed came from the workbook if it was newly proposed.

Deliver language-specific H1, SEO title, meta description and proposed slug where requested. Titles/descriptions need preview and editorial judgment; character ranges are guidance, not ranking rules. Separate publication URLs from suggested slugs.

Internal links: resolve actual pages where possible; otherwise name an opportunity and mark its URL pending. Do not link public copy to private ClickUp/Docs as a substitute. Different language pages normally need their own URLs and appropriate locale/canonical configuration; verify the platform before claiming implementation.

Measure with relevant search/engagement/conversion signals after publication. A report-button click does not establish that someone read the report. No full technical audit, schema implementation or new keyword subscription is implied by a copy task.

Optional helper: keyword_inventory.py returns matching rows only; it does not select strategy, validate demand or evaluate intent.
