# Designer summaries and image briefs

For a full article handoff write a short Arabic summary in 3–5 sentences, default four. Explain the topic, the problem, the example/approach and the takeaway in plain language. Avoid turning it into a list of tools.

Default image count: two total, one cover/thumbnail plus one internal image. A third needs a meaningful separate job; follow an explicit user count. These are written briefs unless the user asks to produce artwork.

Write each brief so the designer can sketch it without decoding abstract language:
1. **Idea:** the single message the viewer should understand.
2. **Scene/composition:** concrete elements, hierarchy, position and relation.
3. **Copy:** short Arabic/English image text for the requested editions.
4. **Placement:** named section from the actual current article.
5. **Brand:** applicable palette/type treatment from the correct profile.
6. **Delivery:** suggested aspect/crop, mobile readability and editable text.
7. **Alt text:** describe the final intended information in each requested language.

The cover attracts interest through the article's central tension. The internal image explains a process, comparison or decision. Do not repeat the cover with another caption. Prefer one strong composition over generic “AI and human collaboration” imagery.

Use diagrams without quantitative geometry when no measured data exists. Never invent percentages, results, tool approvals or client screenshots. Do not imply an agent is a research participant or that automated checks guarantee quality.

Use a current brand skill for actual artwork; bundled writing extracts do not replace its full production rules. Keep the briefs readable rather than prescribing dozens of decorative details. Use an Arabic reading direction and preserve English names/logo orientation.

Full article document: Thumbnail Brief and Image Brief are separate tabs. Card: summary, article link and both briefs. If a brief changes in one place, update the other authorized copy and verify they match.
